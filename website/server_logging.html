What Data Do Website's Need to Function?

Every single time you click on a website there is an exchange of information, the website needs to identify your computer, know what you want to do and then send files back to your browser (usually HTML and CSS). The data your browser has to send to the website is called a request, and the server records these as request logs. An example of what one looks like is shown below: 
{
    "method": "GET",
    "path": "/differentiation.html",
    "ip": "203.0.113.42",
    "headers": {
        "host": "computermath.com",
        "user-agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0.0.0 Safari/537.36",
        "accept": "text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,*/*;q=0.8",
        "accept-language": "en-GB,en;q=0.9",
        "accept-encoding": "gzip, deflate, br",
        "connection": "keep-alive"
    },
    "query_params": {},
    "timestamp": "2026-06-03T10:23:41+00:00"
}
What we get here is a method (what the user wants from our webserver) where the user is trying to get the file/differentiation.html. We also have the ip of the computer that is trying to do this right bellow, this is used to identify who is trying to access your server. Along with this there are a few extra pieces of data, such as the website url (host), the browser used (user-agent) and the language the website is loaded in.
So for this is not that crazy, non of this is personal or identafiable information I can't say who this person is trying to access the webserver, I cant say where they live or anything personal what so ever.
